# Inventory — what exists, and what we can call built

Working list for Loke to sift. Not a launch announcement. Written 9 November 2026 from three passes over the project trees (this machine and pushya share the same project disk), the October company story, and a handful of public host checks the same day.

No network map is in this file. Upstream checkouts we did not write are listed at the bottom so they do not get claimed.

Ratings:

- **On the web** — a public URL answered with the right title.
- **Built** — real code and a record of what it does. Not shown to be up.
- **Running** — we use it ourselves. Not a public product.
- **Partial** — real code, unfinished or contradicted by a check.
- **Design** — specifications, little or no running product.
- **Sketch** — a name, a stub, or a sentence in a catalog.
- **Retired** — stopped on purpose.
- **Upstream** — someone else’s project, present on disk.
