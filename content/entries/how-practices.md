Every studio has these. We write ours down, and we treat them as part of the product.

1. The thing that watches has to be watched. A monitor that has gone quiet is a finding, not a relief.
2. Check the dull cause first. A full disk explains more outages than anything subtle.
3. Run a control before naming a cause on anything noisy.
4. Back up before you flash, and read the docs before you touch the hardware.
5. Restore the existing pattern during a fix. Upgrades get their own day.
6. Cap memory and turn off swap for any local model. Once was enough.
7. Fix a music problem at generation. Never repair it afterwards.
8. Never say "owner" about a Symmate. Bonds and charters, not property.

In October 2026 we had an agent grade the whole record from the folders and commits. Vision and starting got top marks. Finishing and focus did not. We agree with the card, and this page is partly our answer to it: fewer names, more addresses that answer.
